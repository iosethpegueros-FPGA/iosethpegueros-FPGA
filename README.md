# iosethpegueros-FPGA

## Ioseth Pegueros - Senior SoC Emulation Engineer

Welcome to my portfolio of emulation and hardware verification projects.

## About me
Engineer with 15 years of experience in pre-silicon validation at Intel. Specialized in FPGA emulation (HAPS, Xilinx Virtex UltraScale), HW/SW co-verification and currently focusing on UVM methodology.

## Featured Projects
- [MAC_timingClosure](https://github.com/iosethpegueros-FPGA/FPGA_misc_projects/tree/main/MAC_timingClosure) : Timing closure analysis (STA) in Vivado with an intentionally constrained architecture.
- [CDC_top_asyncFIFO](https://github.com/iosethpegueros-FPGA/FPGA_misc_projects/tree/main/asyncFIFO_RTL_CDC) : asynchronous FIFO implementation for cross domain crossing (CDC) analysis. Preparing a DUT for a SystemVerilog testbench and eventually a UVM testbench.
- [behavioral_FIFO](https://github.com/iosethpegueros-FPGA/FPGA_misc_projects/tree/main/Behavioral_FIFO) : Golden model of a FIFO in OOP SystemVerilog, intended to be used as reference for verification tests.
